# Projeto Web - Pastelaria da Sogra

Projeto acadêmico desenvolvido para a disciplina de Web Design.

## Objetivo

Desenvolver um website responsivo e interativo para a Pastelaria da Sogra, com foco na apresentação da empresa, divulgação do cardápio, fortalecimento da presença digital e experiência de compra.

## Tecnologias

- HTML5
- CSS3
- JavaScript
