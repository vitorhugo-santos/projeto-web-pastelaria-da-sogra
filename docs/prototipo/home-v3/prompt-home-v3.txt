==================================================
PASTELARIA DA SOGRA — HOME V3
REGISTRO COMPLETO DE REFINAMENTO DO PROTÓTIPO
==================================================

OBJETIVO GERAL

Refinar a Home V2 da Pastelaria da Sogra até chegar a uma versão visualmente profissional, coerente com a identidade real do estabelecimento e adequada para implementação em HTML, CSS e JavaScript.

A Home V3 deve preservar a identidade visual da Pastelaria da Sogra, utilizando principalmente vermelho, amarelo/dourado, tons creme e cores neutras.

O resultado deve transmitir:
- tradição;
- proximidade;
- fartura;
- confiança;
- presença local em Sorocaba;
- qualidade dos produtos.

O projeto é acadêmico e não deve apresentar o website como site oficial da Pastelaria da Sogra.

Não recriar desnecessariamente partes já aprovadas.

Cada etapa abaixo representa um refinamento realizado sobre a Home existente.

==================================================
DIRETRIZES GERAIS DA HOME V3
==================================================

Não criar uma nova identidade visual.

Preservar a identidade da Pastelaria da Sogra.

Utilizar predominantemente:

- vermelho;
- amarelo/dourado;
- creme;
- branco;
- tons escuros para textos.

Evitar aparência de:

- template genérico;
- site excessivamente gourmet;
- fast-food moderno sem relação com a marca;
- interface carregada;
- excesso de animações;
- elementos desnecessários.

O produto deve continuar sendo protagonista.

Manter forte hierarquia visual.

Manter bom espaçamento entre as seções.

Manter consistência entre:

- botões;
- cards;
- títulos;
- bordas;
- ícones;
- imagens.

As imagens de produtos devem seguir padrão consistente.

As fotografias reais devem ser utilizadas principalmente nas seções institucional e galeria.

A implementação final deverá ser responsiva para:

- desktop;
- tablet;
- smartphone.

A Home deverá utilizar navegação funcional e posteriormente ser integrada às demais páginas do projeto.
