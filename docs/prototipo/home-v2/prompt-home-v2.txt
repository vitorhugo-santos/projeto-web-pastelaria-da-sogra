==================================================
PASTELARIA DA SOGRA — HOME V2
PROMPT DE REFINAMENTO DA HOME V1
==================================================

REFINE A HOME EXISTENTE DA PASTELARIA DA SOGRA.

NÃO crie uma página totalmente nova.

Utilize a Home V1 existente como base e preserve sua estrutura geral, mas corrija problemas de imagens, hierarquia visual, identidade, conteúdo, coerência, credibilidade e usabilidade.

O objetivo é transformar a primeira versão em um protótipo mais profissional, realista e consistente, que posteriormente será utilizado como referência para implementação em HTML, CSS e JavaScript.


==================================================
1. DIREÇÃO GERAL DO PROJETO
==================================================

Este website é um projeto acadêmico desenvolvido para a disciplina de Web Design.

A empresa utilizada como objeto de estudo é:

Pastelaria da Sogra
Sorocaba - SP

Slogan:

“Pastel com recheio de verdade.”

O website deve transmitir:

- tradição;
- fartura;
- proximidade;
- confiança;
- presença local;
- qualidade dos produtos.

O projeto NÃO deve parecer uma reformulação completa da marca.

A proposta é modernizar a presença digital mantendo características visuais associadas à Pastelaria da Sogra.


==================================================
2. IDENTIDADE VISUAL
==================================================

Utilizar como base:

Vermelho profundo:
#B5241C

Amarelo / dourado:
#F4B41A

Creme:
#FFF7E8

Grafite:
#28231F

Branco:
#FFFFFF

O vermelho deve ser a cor principal.

O amarelo/dourado deve ser utilizado principalmente em:

- detalhes;
- pequenos destaques;
- badges;
- ícones;
- elementos de apoio.

Evitar excesso de amarelo.

Utilizar fundo creme ou branco nas principais áreas para manter legibilidade e aparência profissional.

TIPOGRAFIA

Utilizar uma combinação que transmita tradição e modernidade.

Preferência:

Títulos:
Roboto Slab ou fonte serifada equivalente.

Textos e interface:
Inter ou fonte sans-serif equivalente.

A interface deve possuir:

- boa hierarquia;
- bastante espaço entre seções;
- alinhamentos consistentes;
- bordas discretas;
- cards padronizados;
- botões consistentes.

==================================================
19. DIRETRIZES FINAIS
==================================================

O resultado não deve parecer:

- um template genérico;
- um site de restaurante gourmet;
- uma rede de fast-food internacional;
- uma landing page genérica feita por IA.

A identidade precisa continuar relacionada à Pastelaria da Sogra.

Utilizar fotografias reais sempre que forem adequadas.

O produto continua sendo o protagonista.

Evitar excesso de animações e efeitos.

Não misturar imagens.

Não reutilizar imagens de produtos incorretamente.

Não inventar informações para preencher espaços vazios.

Priorizar:

- autenticidade;
- organização;
- clareza;
- credibilidade;
- facilidade de navegação;
- consistência visual.
